# SEMED · Demanda educacional

Painel territorial de Manaus: necessidade de construção por bairro em 2021 e educação infantil por DDZ em 2026.

## Acesso

[Abrir o painel](https://charles-igeotecnologia.github.io/SEMED-Demanda-educacional/)

O arquivo `index.html` contém o painel completo e pode ser baixado para uso local. Satélite (Esri) e ruas (OpenStreetMap) exigem internet. Os dados incorporados, a base local, os filtros e as exportações são processados no navegador.

## Recursos

- 2021: mapa de bairros, calor, rótulos prioritários, ranking, escolas necessárias nas quatro etapas e relatório PDF horizontal.
- 2026: indicadores e gráficos por DDZ, creche e pré-escola/CMEI, quadro síntese e relatório PDF horizontal.

## Fontes e interpretação

Departamento de Planejamento | DGTI - Geotecnologia.

Fonte 2021: MEC/INEP/IBGE/SEMED/DEPLAN/DIE, conforme a base fornecida. A malha atualizada não comprova equivalência com os limites de 2021. Ausência de dados difere de zero. Os quantitativos de construção são os prédios documentados na fonte, sem recálculo automático e sem indicação de obras executadas.

Fontes 2026: documentos fornecidos de unidades (maio/2026), matrículas (01/10/2026) e vagas disponíveis (20/10/2026). Os indicadores usam as tabelas documentais; as divergências da imagem de referência estão descritas no painel. Os PDFs de referência estão incorporados e disponíveis para consulta.

Os dados apresentados são agregados territorialmente. Esta publicação inclui o HTML com seus dados, imagem de referência e PDFs incorporados; não inclui as planilhas, os Shapefiles originais nem os arquivos intermediários de desenvolvimento.
